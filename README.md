# 헤아림 HearI'm

QR을 찍고 고르면 결과가 바로 화면에 올라오는 실시간 설문 · 퀴즈.

주소: https://musicalpe.github.io/hearim/

- 참여하는 사람: 가입·설치 없이 QR이나 설문 번호로 들어와 고르거나 적어서 내요. 이름이나 연락처는 받지 않아요.
- 만드는 사람: 구글 계정으로 로그인해 질문을 적으면 설문 번호와 QR이 생겨요. 질문 10개까지 한 번에 만들고 순서를 바꿀 수 있어요.
- 결과 화면: 큰 화면에 띄워 두면 답이 들어오는 대로 막대·원 그래프와 답 구름이 올라와요. 발표 모드로 질문·QR·결과만 크게 보여 줄 수 있어요.
- 설문: 하나 고르기, 여러 개 고르기(개수 제한 가능), 적어서 내기(같은 답은 글씨가 커져요), 한 줄 의견.
- 퀴즈: 함께 풀기(정답 보이기), 혼자 풀기(번호로 들어와 맞은 개수를 각자 확인, 큰 화면에는 분포만), 골든벨(틀리면 탈락, 부활 문제).
- 미리보기: https://musicalpe.github.io/hearim/?demo 로 열면 로그인 없이 지어낸 설문·퀴즈·골든벨을 만들고 답해 볼 수 있어요. 이 브라우저 안에서만 돌고 실제 자료는 건드리지 않으며, 12시간이 지나면 처음 상태로 돌아가요.
- 앱처럼 쓰기: 휴대폰 홈 화면이나 PC에 앱으로 설치할 수 있어요. 첫 화면 오른쪽 위 사용 안내에 방법이 있어요.

## 파일

- `index.html` 앱 전체 (첫 화면·참여 `?p=번호`·결과 화면 `?b=번호`)
- `config.js` 파이어베이스 연결 정보
- `demo.js` 미리보기(`?demo`) — 브라우저 안의 가짜 데이터베이스와 지어낸 설문
- `database.rules.json` 실시간 데이터베이스 규칙
- `qrcode.js` QR 만들기 (Kazuhiko Arase, MIT)
- `icon.svg` `icon-192.png` `icon-512.png` 아이콘 · `og.png` 주소를 보낼 때 뜨는 그림(1200×630)
- `manifest.webmanifest` `sw.js` 앱으로 설치하기
- `promo/` 소개 사진
- `dev/` 시험 도구: `python3 dev/test_app.py` (가짜 데이터베이스와 가짜 SDK로 전체 흐름을 돌려요)

## 올리기 전 점검

기능을 고쳤으면 `python3 dev/test_app.py` 가 모두 통과하는지 보고 올려요. 글귀·색만 고쳤으면 문법 검사와 화면 확인만.
